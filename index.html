OOP Explorer

Understand classes, objects, inheritance, and polymorphism.

Class and object

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def grade(self):
        if self.marks >= 80:
            return "Excellent"
        return "Keep practising"

student = Student("Aarav", 85)
print(student.grade())

The class defines a student; the object stores the student's values.

Inheritance and polymorphism

class Animal:
    def speak(self):
        return "Animal sound"

class Dog(Animal):
    def speak(self):
        return "Woof!"

pet = Dog()
print(pet.speak())

Dog inherits from Animal and overrides its method.

Geometry managers

Tkinter runs as a desktop application, not inside a browser page.

import tkinter as tk

root = tk.Tk()
root.title("Synapse AI - Tkinter Lab")
root.geometry("500x300")

tk.Button(root, text="Pack").pack(pady=8)

button = tk.Button(root, text="Grid")
button.grid(row=0, column=0, padx=10)

root.mainloop()

For a real demonstration, run the separate Tkinter program provided in the desktop module. Do not mix pack() and grid() in the same parent container.
